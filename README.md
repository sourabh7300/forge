# ⚒️ Forge

> Write the skeleton. Forge the rest — instant starter code for any language.

**🔴 Live demo:** https://sourabh7300.github.io/forge/

## What it does
- Pick a language, get a clean, idiomatic starting template
- Multi-language support (JavaScript, Python, HTML and more)
- Copies straight to your editor — zero setup
- For when `git init` feels like too many decisions

## Built with
HTML · CSS · JavaScript — **zero frameworks**, single file, runs in any browser.
